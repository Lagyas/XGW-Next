# Stage 111 — track ordering GUI

Added Edit menu actions for moving the selected track up or down. The operation validates against a copy, moves track routing and XWS source properties together, updates mute/solo track indices, refreshes the track list and selects the moved track. MIDI event contents are untouched. Staff Editor remains paused.

Git operations are not included in this archive: no .git metadata was present in the stage 110 source archive.
